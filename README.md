# CertScope

CertScope собирает открытые сертификаты из файлов и хранилищ Windows и показывает, где они обнаружены. Для запуска нужна Windows 10 с .NET Framework 4.5 или новее.

## Первый запуск

1. Скопируйте папку `app` целиком туда, где у вас есть право записи. Запустите `CertScope.exe`.
2. Откройте **Настройки → Демо: файлы организаторов** и нажмите **Сканировать**. На вкладке **Сертификаты** должны появиться два образца. Для этого достаточно локального ПК.
3. Откройте строку сертификата двойным щелчком или нажмите **Экспорт** и выберите XLSX, TXT либо CER. XLSX и TXT сохраняют отдельный отчёт об источниках.

## Сканирование

- **Файлы.** Нажмите **Импорт** для отдельных файлов. Для обхода папки укажите её в **Настройки → Каталоги**. Для сетевой папки укажите UNC-путь вида `\\ИМЯ-ПК\ОбщийРесурс` с правом чтения.
- **Этот ПК.** В поле **Компьютеры** укажите `localhost`. Для машинных хранилищ включите **LocalMachine**, для загруженных профилей — **Профили / HKU**. Для обхода отдельного хранилища впишите его путь в **Дополнительные ветки**.
- **Другой ПК.** Подготовьте целевой компьютер скриптом из `deploy` и задайте учётку и хранилища по [инструкции для рабочей группы и домена](docs/target-setup.md).

После сканирования проверьте вкладку **Охват и ошибки**. Результаты копятся в `data`, журналы находятся в `logs`. Чтобы начать с пустого списка, в **Настройки → Рабочие данные** задайте новый каталог и нажмите **Сохранить настройки**. При публикации храните рабочие данные и экспорт вне репозитория.

## Синхронизация с SQL Server 2019

Сканирование работает локально. Если нужна синхронизация, подготовьте существующую БД. Администратор БД может заранее применить [схему](sql/schema.sql). В настройках укажите строку подключения с Windows-аутентификацией и нажмите **Синхронизация SQL**. Для подключения используются права пользователя, запустившего CertScope.

```text
Data Source=localhost;Initial Catalog=CertScope;Integrated Security=True;Encrypt=True;TrustServerCertificate=False
```
